4.) I picked SIGTERM (signal 15, "Termination signal"). It terminates the
sleeping process.

5.) Pressing Ctrl-C sends SIGINT to the foreground process group, which
includes both the caller and its sleeper child. Both processes terminate,
so the caller does not print its success message.

6.)
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>

void handle_sigint(int signum)
{
    (void) signum;
    printf("Caller is ignoring SIGINT.\n");
}

/* In main(), before fork(): */
if (signal(SIGINT, handle_sigint) == SIG_ERR) {
    perror("Could not register SIGINT handler");
    return EXIT_FAILURE;
}
