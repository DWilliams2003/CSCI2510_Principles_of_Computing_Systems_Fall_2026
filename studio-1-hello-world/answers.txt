Difference between the function signatures of fprintf() and printf():
printf()
int printf(const char *format, ...);
It takes only a format string (plus optional variadic arguments).

fprintf() 
int fprintf(FILE *stream, const char *format, ...);
It takes an extra first argument: a FILE* stream (e.g., stdout, stderr, or a file you opened).
