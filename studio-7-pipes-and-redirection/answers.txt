3.) After pipe(fd) succeeds, fd[0] is the read end and fd[1] is the write end.

4.) dup2(oldfd, newfd) closes the second argument (newfd) if it’s open and differs from oldfd, then makes it refer to the same open file description as oldfd. 
If both arguments are the same, it closes nothing.

5.)
dup2(fd[1], STDOUT_FILENO); /* Program 1 writes to the pipe */
dup2(fd[0], STDIN_FILENO);  /* Program 2 reads from the pipe */

8.) 
Programs are reusable and composable: A program that reads stdin or writes stdout can be connected to different programs with pipes or redirection, without changing its code.
The I/O destination can change independently: The same program can use a terminal, file, pipe, or socket. The operating system handles the connection, keeping programs decoupled 
from the details.
